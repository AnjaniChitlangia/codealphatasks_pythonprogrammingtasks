# Basic Chatbot

A rule-based chatbot in Python with pre-defined replies. It greets you with
good morning / afternoon / evening based on the time you send the message.

## Replies
| You type | Chatbot replies |
|---|---|
| hi / hello | Hello! Good morning / afternoon / evening! |
| how are you | I am fine, thank you. What about you? How was your day? |
| what are you doing | Waiting to help you! |
| can you please help me | Sure! |
| wait | Yes sure! Waiting. |
| thanks | You're welcome! |
| bye | Goodbye! Have a good morning / afternoon / evening! |

## Run
```
python chatbot.py
```

See `sample_conversation.txt` for an example chat.
